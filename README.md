# 🌿 EcoMind  
**AI-Powered Sustainability Tracker & Environmental Insights Dashboard**

EcoMind is an intelligent sustainability platform that analyzes environmental data, tracks carbon impact, and visualizes actionable insights for individuals, companies, and policymakers.  
Built with an AI-driven backend and a clean Streamlit interface, EcoMind empowers users to understand and reduce their ecological footprint.

---

## 🌍 Overview
As climate change continues to accelerate, the need for accessible and interpretable sustainability data is more important than ever.  
**EcoMind** bridges the gap between raw environmental datasets and meaningful climate intelligence.

Key Objectives:
- Monitor and visualize carbon footprint trends  
- Evaluate the impact of energy use, waste, and transportation  
- Provide AI-driven recommendations for sustainable improvements  
- Translate complex data into clear, actionable visual insights  

This project demonstrates practical applications of **AI for environmental science**, **data visualization**, and **human-centered sustainability design**.

## ⚙️ Tech Stack
| Category | Tools & Libraries |
|-----------|------------------|
| Frontend UI | [Streamlit 1.37](https://streamlit.io) |
| Data Processing | [Pandas 2.2](https://pandas.pydata.org), [NumPy 1.26](https://numpy.org) |
| Visualization | [Plotly Express](https://plotly.com/python/), [Matplotlib 3.8](https://matplotlib.org) |
| Machine Learning | [Scikit-learn](https://scikit-learn.org), [TensorFlow Lite] (optional for predictive modeling) |
| Data Source | Custom CSV dataset (`sample_models.csv`) for emissions and energy statistics |
| Reporting | Streamlit charts, downloadable summaries, and trend analytics |

---

## 🧩 Core Features
- **Carbon Tracker** — Estimate and visualize CO₂ emissions from key sectors  
- **Impact Dashboard** — Real-time metrics and trend visualizations for sustainability goals  
- **AI Insight Generator** — Uses regression and clustering models to detect inefficiencies  
- **Custom Dataset Support** — Upload local environmental datasets for instant analysis  
- **Predictive Analytics** — Forecasts future emissions under different sustainability plans  

---

## 🧠 Methodology Summary
1. **Data Collection:** Ingests structured sustainability metrics from `sample_models.csv` or uploaded user data.  
2. **Preprocessing:** Cleans, scales, and normalizes metrics for model analysis.  
3. **Model Evaluation:** Applies machine learning algorithms (e.g., regression, clustering) to uncover trends.  
4. **Visualization & Reporting:** Displays results via dynamic Streamlit dashboards and downloadable summaries.  

This framework reflects key principles of **AI for Social Good** and **Responsible Data Visualization**.

## 💻 Installation & Usage
```bash
# Clone the repository
git clone https://github.com/AbdiqafarOmar/EcoMind.git
cd EcoMind

# Create and activate a virtual environment
python3 -m venv .venv
source .venv/bin/activate   # macOS / Linux
# .venv\Scripts\activate    # Windows

# Install dependencies
pip install -r requirements.txt

# Launch the Streamlit app
streamlit run streamlit_app.py
